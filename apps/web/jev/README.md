# Jev в Second opinion

Два decision-пункта на TypeSafe Jev, код — `lib/jev.ts`. Доступ: прямой API TypeSafe (`POST https://api.typesafe.ai/v1/systemone`, ключ `TYPESAFE_API_KEY`, модель `jev-latest`) или OpenRouter Decisions API (`POST /api/alpha/decisions`, `OPENROUTER_API_KEY`, `typesafe/jev-1.13`) — формат запроса одинаковый, выбирается по ключу или `JEV_PROVIDER`.

1. **Маршрутизация реплики** (`routeMessage`): Choice по 9 намерениям из `INTENTS` + Noul «названа ли бумага».
   При уверенности ≥ `JEV_THRESHOLD` (0,8) гейт (`lib/gate.ts`) вызывает инструмент напрямую — без LLM.
   Намерения `pick_variant` и `ask_about_report` всегда уходят модели.
2. **Разбор «сколько обещали»** (`parsePromise`): Choice по `PROMISE_KINDS` — годовая / купон / за срок / за период / не обещание.
   Число берётся регуляркой (рядом с «обещали», со знаком %, иначе первое ≤ 100); «за срок» не подставляется, а переспрашивается.

Без ключа или при `JEV_ENABLED=0` работает правило-фоллбэк (`routeByRules`, `promiseByRules`) — детерминированный, им же идут тесты.

## Проверка перед доверием порогу

`router-phrases.jsonl` — 50 реплик с ручной разметкой намерения и контекстом (`report_shown`).
Прогон через `jev:check` (или `scripts/jev-eval.ts` с ключом в `.env`) должен дать: совпадение ≥ 90% на уверенных ответах
(≥ 0,8) и ноль ошибок класса «не по теме → проверить бумагу». Пока не прогнано на живом Jev — порог 0,8 взят из тестов на раскрытии (29–30.09.2026).

Строки «26» и «0,3» (голые числа при показанном отчёте) — заведомо неоднозначные: ожидаем низкую уверенность и уход к модели, не угадывание.
«1 000 000» при показанном отчёте — не двусмысленно: миллион может быть только суммой позиции (Jev даёт 0,98, и это верно).

## Живой прогон 08.10.2026 (jev-latest, прямой API TypeSafe)

54/54 совпадений с разметкой; уверенных (≥ 0,8) 49/54, из них верных 49; уверенных ошибок 0; на «26» и «0,3» —
неуверенно (правильно). Правила на том же наборе: 51/54, уверенных 42/54, ошибок 0. Порог 0,8 подтверждён.
В чате за 4 реплики (приветствие, «который час», ругань, «ОФЗ-26243-ПД») гейт исполнил всё сам, без LLM; ~1 650 входных
токенов на решение ≈ $0,07 на 1000 сообщений. TypeSafe не возвращает `usage.cost` — стоимость считается по прайсу.
HTTP 402 `billing_error` = нет кредитов на организации TypeSafe (ключ при этом валиден); сервис падает на правила.
