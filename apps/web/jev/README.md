# Jev в Second opinion

Два decision-пункта на TypeSafe Jev (OpenRouter Decisions API, `POST /api/alpha/decisions`), код — `lib/jev.ts`:

1. **Маршрутизация реплики** (`routeMessage`): Choice по 9 намерениям из `INTENTS` + Noul «названа ли бумага».
   При уверенности ≥ `JEV_THRESHOLD` (0,8) гейт (`lib/gate.ts`) вызывает инструмент напрямую — без LLM.
   Намерения `pick_variant` и `ask_about_report` всегда уходят модели.
2. **Разбор «сколько обещали»** (`parsePromise`): Choice по `PROMISE_KINDS` — годовая / купон / за срок / за период / не обещание.
   Число берётся регуляркой (рядом с «обещали», со знаком %, иначе первое ≤ 100); «за срок» не подставляется, а переспрашивается.

Без ключа или при `JEV_ENABLED=0` работает правило-фоллбэк (`routeByRules`, `promiseByRules`) — детерминированный, им же идут тесты.

## Проверка перед доверием порогу

`router-phrases.jsonl` — 50 реплик с ручной разметкой намерения и контекстом (`report_shown`).
Прогон через `jev:check` (или `scripts/jev-eval.ts` с ключом в `.env`) должен дать: совпадение ≥ 90% на уверенных ответах
(≥ 0,8) и ноль ошибок класса «не по теме → проверить бумагу». Пока не прогнано на живом Jev — порог 0,8 взят из тестов на раскрытии (29–30.09.2026).

Последние три строки (голые числа «26», «1 000 000», «0,3») — заведомо неоднозначные: ожидаем низкую уверенность и уход к модели, не угадывание.
