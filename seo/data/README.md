# seo-data — выгрузки для SEO-цикла

Отдельная ветка только с данными. Код сайта здесь не лежит.

- `webmaster-YYYY-MM-DD.md` — еженедельная выгрузка Яндекс Вебмастера по mkt-second-opinion.ru: сводка, диагностика, страницы в поиске, статистика запросов, мониторинг. Её кладёт задача по расписанию (понедельник утром), которая читает Вебмастер в браузере владельца. Только чтение, настройки Вебмастера задача не меняет.
- Workflow `seo-loop.yml` перед запуском Claude копирует папку `seo/data` из этой ветки в рабочее дерево (`git checkout origin/seo-data -- seo/data`).

Секретов и персональных данных здесь нет и быть не должно: только агрегаты (запросы, показы, клики, позиции, статусы страниц).
