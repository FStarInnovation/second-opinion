# Семантическое ядро — mkt-second-opinion.ru

Источник: Яндекс Вебмастер, «Подбор запросов и анализ рынка (β)», 24.10.2026, все устройства. 20 стартовых запросов (проверить облигацию, доходность, доходность к погашению, ликвидность, рейтинг, структурные облигации и продукты, стоит ли покупать, калькулятор доходности, НКД, анализ, риски, дефолт, какие купить, простыми словами, финансовый советник, ISIN, ВДО, купонный доход, Мосбиржа). В инструменте висит плашка «временно не обновляются данные» (сбой Яндекса), цифры — последние доступные. «Спрос» и «Клики» — как в инструменте; запросов «банк предлагает инвестировать» и по ISIN почти нет.

Сайт пока закрыт для поиска (`SO_PUBLIC` не задан) — ядро нужно для текстов и новых страниц к открытию; эффект в поиске измерим только после него.

## Предложения для цикла (по одной-две за запуск, после открытия сайта)
1. **Title и description главной** под «калькулятор доходности облигаций». Варианты: «Калькулятор доходности облигаций с комиссией и налогом — Second opinion» (62 знака); «Second opinion — реальная доходность облигации по данным Мосбиржи» (63). Description: «Реальная доходность облигации после комиссии и НДФЛ, ликвидность и риски по данным Мосбиржи. Введите ISIN или название — без регистрации.» Факты — только из текстов главной.
2. **Title /check**: «Проверка облигации: доходность, ликвидность, риски — Second opinion».
3. **Страницы-глоссарий** (новые адреса — решение владельца): НКД, доходность к погашению, дюрация, флоатер, оферта и колл. Тексты — из FAQ и словаря ассистента (`apps/web/lib/glossary*`), без новых фактов.
4. **Страницы выпусков** (`/bond/<ISIN>` с отчётом) — самый большой спрос (эмитенты + «стоит ли покупать»), но это новая функция продукта и вопрос юриста: формулировки «не является инвестиционной рекомендацией».

## Что проверить через 30 дней после открытия
Показы и клики главной по кластеру «калькулятор доходности облигаций» (Вебмастер, «Статистика запросов»), CTR сниппета, позиции в «Мониторинге».
