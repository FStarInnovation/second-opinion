# План: устранение находок разбора диалогов (WP-U)

**Дата:** 13.10.2026 · **Основание:** `docs/DIALOGS_REVIEW_2026-10-12.md` · **Харнес:** проверки U.1–U.23 (`apps/web/audit/checks/wp-u-gate.ts`, `wp-u-ui.ts`, `packages/engine/src/audit/checks/wp-u.ts`), до правки 22 RED · 1 guard GREEN · **Исполнители:** Opus 5.5 · **Ревью:** два независимых на пакет (Fable 5.1, при исчерпанном лимите — Opus 5.5) · **Эталоны:** `golden:write` — только оркестратор после разбора диффа · **Выкатка:** только по явному «катить».

## Принципы

- Числа считает движок, модель чисел не пишет. Правки гейта и UI не добавляют чисел в текст модели.
- Проверку можно поменять, только если она отвергает разумное исправление. Решение обосновывается в отчёте, ревьюер его подтверждает. Ослаблять проверку до тавтологии нельзя.
- Ничего, что было GREEN, не краснеет: `audit -- --baseline` в обоих пакетах, `selftest`, `typecheck`.
- Поведение Jev не меняем: описания интентов и порог остаются прежними, так как перепроверить порог без платных вызовов нельзя. Всё новое — детерминированные правила гейта.

## Приёмка

1. `npm run -s -w @so/engine audit -- --only U` и `AUDIT_LIVE=1 npm run -s -w @so/web audit -- --only U` — GREEN, кроме U.15 и U.16 до выкатки (живые, смотрят прод).
2. `npm run -s -w @so/engine audit -- --baseline` и `npm run -s -w @so/web audit -- --baseline` — exit 0. Перевороты вверх (H.2, H.7-health, R.6-web и др.) перечислить.
3. `npm run -s selftest`, `typecheck` обоих пакетов, `npm run -s golden:diff` — дифф объяснён.
4. После выкатки — U.15 и U.16 на проде GREEN и ручная проверка в браузере: выбор выпуска в чате, индикатор ожидания, «вложу 2 млн, комиссия 0,3%», «Срок драции», «предложи ты бумагу».
